# Spec Delta

## Purpose

コメントを送れたらリアクションのシートを閉じ、自分のコメントが流れて欄に並ぶのを見られるようにする。

## MODIFIED Requirements

### Requirement: COMM-01 コメントを送る

パブリックSpaceに入室している人は、ロールにかかわらず30字（書記素で数える）までのテキストのコメントを送れなければならない（MUST）。コメントは入室者全員に届け、特定の相手にだけ送る方法を提供してはならない（MUST。PART-10）。入室していない人と、退室させられた人のコメントは受け付けない（MUST）。botたんSpaceではコメントの操作を出さず、サーバーも受け付けない。送信はマイクの許可を必要としない。コメントが送れたら、入力欄を空にしてリアクションのシートを閉じ、操作バーの「リアクション」にフォーカスを戻す（MUST）。送れなかったときは、シートを開いたまま書いた文面を残し、理由を表示する（MUST）。

#### Scenario: 聴衆がコメントを送る

- **WHEN** 聴衆が「わかる」と書いて送る
- **THEN** 入室者全員の画面に、そのコメントが送った人の表示名とアイコンとともに表示される

#### Scenario: 30字を超える

- **WHEN** 参加者が31字以上のコメントを送ろうとする
- **THEN** 送信の操作は使えず、30字までであることが表示される。サーバーに直接送っても受け付けない

#### Scenario: 入室していない人が送る

- **WHEN** Space に入室していないログイン済みの利用者が、コメントの API を直接呼ぶ
- **THEN** サーバーは拒否し、誰にも届かない

#### Scenario: botたんSpace

- **WHEN** ホストが botたんSpace のリアクションのシートを開く
- **THEN** コメントの入力欄は表示されない

#### Scenario: コメントを送るとシートが閉じる

- **WHEN** 参加者がコメントを書いて送り、送信が成功する
- **THEN** シートが閉じ、自分の送ったコメントが流れるのと「字幕とコメント」の欄に並ぶのが見える

#### Scenario: コメントが送れない

- **WHEN** 連投の制限か通信の失敗でコメントが送れない
- **THEN** シートは開いたままで、書いた文面が入力欄に残り、理由が表示される
