# Proposal

## Why

Space で声を出さずに参加できる手段が絵文字だけで、「わかる」「それ聴きたい」のような短い反応を言葉で返せない。また、初めて入った人が「どうすれば話せるのか」「botたんとは何か」「録音されるのか」を確かめる場所が無い。短いテキストのコメントと、使い方をまとめたヘルプを足す。

## What Changes

- **コメント**：入室している人は誰でも（聴衆を含む）、30字までのテキストを Space に送れる。届くのは入室者全員で、特定の相手にだけ送る方法は作らない（PART-10）。
  - 送ったコメントは、絵文字と同じく画面の上を流れて数秒で消える。
  - 字幕の欄を「字幕とコメント」にして、字幕とコメントを届いた順に1つの欄に並べる。コメントは送った人のアイコンと吹き出しの印で字幕と見分けられる。欄には入室してからの分だけを、直近200件まで残す。下までスクロールしているときだけ新しい行を自動で追う。
  - 保存しない。ミュートしている人のコメントは自分の画面に出さない。混雑時の字幕の一時停止はコメントには及ばない。連投は制限する。
  - botたんはコメントを読まない（返事は今までどおり声にだけする）。
  - 送る場所：操作バーの「絵文字」を「リアクション」にし、開くシートの上に入力欄、下に絵文字を並べる。
- **ヘルプ**：ヘッダーの「?」から、Space の使い方をまとめたモーダルを開ける。中身は、聴く・話す（発話のリクエスト）・リアクション（絵文字とコメント）・botたん・字幕とコメント・通報・保存しないこと。

## Capabilities

### New Capabilities

- `space-comments`：Space へのテキストのコメントの送信・表示・連投の制限・保存しないこと。
- `space-help`：使い方をまとめたヘルプのモーダル。

### Modified Capabilities

- `space-participation`：PART-10（入室者全員に同じように届けるものにコメントを加える）、PART-07（通報に含めないものにコメントを加える）。

## 非対象

- コメントへの返信・いいね・削除・編集
- ホストによるコメントの削除やコメントだけの禁止（退室処分 PART-06 と通報 PART-07 で扱う）
- botたんがコメントを読んで返事すること
- コメントの保存・あとからの閲覧
- 言葉の自動の検閲・フィルター

## 法規との関係

コメントはパブリック Space の入室者全員に同じように届き、特定の利用者の間だけに閉じたやり取りにはならない。オープン・チャット（誰でも入れる「場」）の性質は変わらず、届出が要らない前提（proposal「法規との関係」、2026-11-27 の判断）を保つ。botたんSpace は人間がホスト1人だけで、コメントを読む相手がいないため、コメントの操作を出さない。

## 影響

- **本リポジトリ**：コメントを受け付ける API（`src/routes/s/[id]/comment/`）、コメントの検証と連投の制限（`src/lib/server/spaces/`）、リアクションのシート（`src/lib/space/Reactions.svelte`）、字幕の欄（`src/lib/space/Captions.svelte`）、ヘッダー（`src/lib/ui/SiteHeader.svelte`）とヘルプのモーダル、日英の文言、E2E。
- **外部リポジトリ・外部サービス**：変更なし。コメントは今のリアクションと同じく LiveKit のデータメッセージで配る。
- **個人情報**：コメントの文面は中継するだけで、本アプリの保存先・ログ・PDS に書かない。

## 確認して決めた事項（2026-11-27）

| 決定 | 反映先 |
|---|---|
| 流して消し、字幕の欄を「字幕とコメント」として共用する | COMM-02 |
| 1件30字まで | COMM-01 |
| botたんはコメントを読まない | COMM-05 |
| ヘルプはヘッダーの「?」から開く | HELP-01 |

## 推奨案で決めた事項（2026-11-27 利用者が了承）

1. **コメントの連投の制限**：1人あたり10秒に3件まで（絵文字の8件とは別に数える）。
2. **botたんSpace ではコメントの操作を出さない**：読む相手がいないため。
