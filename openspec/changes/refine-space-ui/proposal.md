# Proposal

## Why

最初の公開版は機能を優先したため、画面が試作品のままになっている。botたんの3Dモデルは最大でも幅320px程度の小さな枠に収まり、絵文字は画面の端に小さく流れるだけで、Spaceの「場の盛り上がり」が伝わらない。ログインしていない人がトップを開いても、Nagi Spaceが何をする場所かの説明が無い。ボタンを押してから応答までに数秒かかる操作でも、押せたかどうかが分からない。Nagiの姉妹アプリとして、Nagi本体と同じ手触りの画面に仕上げる。

## What Changes

- **ランディングページ**：ログインしていない人がトップ（`/`）を開くと、Nagi Spaceの説明（何ができるか、botたんを呼べること、聴くだけでも参加できること、Nagiのアカウントで入れること）とログインへの導線を表示する。ログイン中は、今までどおり開催中のSpaceの一覧を表示する。
- **Space画面の作り直し**：
  - botたんの3Dモデルを、Space画面の主役として大きく表示する（スマートフォンでは画面の幅いっぱい）。
  - 絵文字リアクションを、画面の上を大きく流れる形で表示する（送った人のアイコン付き）。
  - スピーカーと聴衆を、Nagiのプロフィールのアイコン付きで並べ、話している人を枠の光り方で示す。
  - マイク・絵文字・発話のリクエスト・退室などの操作を、画面の下の操作バーにまとめる。
- **待ち時間の表示**：Spaceの開始、入室、発話のリクエストと承認、botたんの招待、通報の送信、シェアの再試行、終了など、応答を待つ操作では、ボタンに回転するスピナーを出し、二重に押せないようにする。
- **全体の見た目**：トップ・ログイン・Spaceの開始・Space画面・終了画面を、Nagi本体のボタン・カード・見出し・余白の作りに合わせて整える。配色は今までどおりNagiのデフォルトテーマ（bot-mint）で、ライト・ダークの切り替えも保つ。仕上げに unslop スキルの手順で、試作品らしさ（不揃いの余白、下線だけのボタン、飾りの無い一覧など）を取り除く。
- 機能・権限・保存するデータは変えない。参加者のアイコンを出すため、LiveKitの参加者情報にNagiのプロフィールのアイコンのURL（公開の情報）を含める。

## Capabilities

### New Capabilities

- `space-landing`：ログインしていない人向けのトップ（Nagi Spaceの説明とログインへの導線）。

### Modified Capabilities

- `space-appearance`：LOOK-01（Nagiのテーマに合わせる範囲を、ボタン・カード・見出しの作りまで広げる）、LOOK-05（スマートフォンでの配置を、新しいSpace画面の構成に合わせる）を変え、Space画面の構成（LOOK-07）と待ち時間の表示（LOOK-08）を加える。
- `bot-tan-presence`：BOT-05（3Dモデルを画面の主役として大きく表示する）。
- `space-reactions`：REACT-01（絵文字を画面に大きく表示する）。

## 非対象

- 機能の追加・削除（新しい操作、権限、上限、保存するデータは変えない）
- Nagiの他の配色テーマ（latte-pinkなど）への対応
- botたんの3Dモデルそのもの・動き・声の変更
- Nagi画面内への「開催中のSpace」の表示（引き続き別のchangeで扱う）

## 影響

- **本リポジトリ**：画面のコンポーネント（`src/routes/`、`src/lib/space/`、`src/lib/ui/`）、共通のスタイル（`src/routes/layout.css`）、日英の文言（`src/lib/i18n/messages.ts`）、LiveKitのトークンの参加者情報（`src/lib/server/spaces/livekit.ts`）、E2Eテストの画面の指定。
- **外部リポジトリ**：変更なし。Nagi本体（`../nagi_client`）は見た目の参考として読むだけ。botたんの画像を流用する場合は、Nagi本体の `static/` から本リポジトリへ写す（未決事項2）。
- **外部サービス**：変更なし。

## 未決事項

1. **LPの文面**：見出し・説明・特徴の文面は案を作って示し、確認をいただいてから確定する。
2. **botたんの画像の流用**：LPの見出しの絵に、Nagi本体の `static/bot_image_hero_trans.webp` などを流用してよいか。
3. **絵文字の表示の大きさと時間**：案は「画面の下から上へ約3秒かけて流れ、絵文字は48px程度」。実際に見て調整する。
