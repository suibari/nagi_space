# Spec Delta

## Purpose

絵文字リアクションを画面に大きく表示し、その場の盛り上がりが伝わるようにする。

機能一覧：

| 要件ID | 機能 | 変更 |
|---|---|---|
| REACT-01 | 絵文字を送る | 表示の大きさと出し方を定める |

## MODIFIED Requirements

### Requirement: REACT-01 絵文字を送る

入室中の参加者は、ロールにかかわらずSpaceへ絵文字を送れなければならない（MUST）。送った絵文字は、送った人のアイコンとともに入室者全員の画面に短時間だけ表示する。ただし、送った人をNagiでミュートしている入室者の画面には表示しない（PART-09）。送信はマイクの許可を必要としない。絵文字は、Space画面の上を下から上へ流れる形で大きく表示する（MUST）：絵文字は文字の3倍程度（40px以上）、送った人のアイコンを添え、数秒で消える。同時にたくさん届いても、画面の操作（操作バー・ボタン）を覆って押せなくしてはならない（MUST）。端末で「視差効果を減らす」を選んでいる人には、流さずにその場で表示して消す。

#### Scenario: 聴衆が絵文字を送る

- **WHEN** 聴衆が絵文字を1つ選んで送る
- **THEN** 入室者全員の画面に、その絵文字が送った人のアイコンとともに大きく表示され、下から上へ流れて消える

#### Scenario: 絵文字が一度にたくさん届く

- **WHEN** 数人が続けて絵文字を送る
- **THEN** 絵文字は重なりながら流れ、操作バーのボタンは押せるままである

#### Scenario: 視差効果を減らしている

- **WHEN** 端末で「視差効果を減らす」を選んでいる入室者に絵文字が届く
- **THEN** 絵文字は流れずにその場で表示され、数秒で消える
