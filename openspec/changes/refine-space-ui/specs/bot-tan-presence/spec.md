# Spec Delta

## Purpose

botたんがSpaceに参加している間、3Dモデルを画面の主役として大きく表示する。

機能一覧：

| 要件ID | 機能 | 変更 |
|---|---|---|
| BOT-05 | 3Dモデルの表示 | 表示の大きさを定める |

## MODIFIED Requirements

### Requirement: BOT-05 3Dモデルの表示

botたんが参加している間、入室者全員の画面にbotたんの3Dモデル（VRM）を表示し、待機の動き、話している間の口の動き、返事に合わせた体の動きを再生しなければならない（MUST）。3Dモデルは、Space画面の見出しのすぐ下に、画面の主役として大きく表示する（MUST）：スマートフォン（幅640px未満）では画面の幅いっぱい、それより広い画面では中央の段の幅いっぱい（640px程度）とし、上半身が画面の高さの半分ほどを占める大きさにする。3Dを表示できない端末では、botたんのアイコンを同じ場所に大きく表示する。

#### Scenario: botたんが話す

- **WHEN** botたんが返事を話す
- **THEN** 3Dモデルの口が音声に合わせて動き、返事に合った体の動きを再生する

#### Scenario: スマートフォンで表示する

- **WHEN** 幅360pxの画面でbotたんが参加しているSpaceを開く
- **THEN** 3Dモデルが画面の幅いっぱいに表示され、横スクロールは出ない

#### Scenario: WebGLが使えない

- **WHEN** 入室者のブラウザでWebGLが使えない
- **THEN** 3Dモデルの代わりにbotたんのアイコンを同じ場所に大きく表示し、音声と字幕は通常どおり届く
